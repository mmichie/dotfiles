,tt: open a new tab
,tc: close the tab
,tn / ,tp: next / previous tab
Ctrl+H/J/K/L: move to the window on the left, below, above or right
,Space: clear the search highlighting
,e: toggle the file explorer (Neo-tree)
gd: go to the definition (LSP)
grr: list the references (LSP)
K: show the documentation for the symbol under the cursor (LSP)
,rn: rename the symbol under the cursor (LSP)
,ca: code actions (LSP)
,F: format the buffer (LSP)
