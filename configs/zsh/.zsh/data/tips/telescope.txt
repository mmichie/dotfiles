,ff: find files
,fg: search the text of every file (live grep)
,fb: pick an open buffer
,fh: search the help tags
Ctrl+N / Ctrl+P: next / previous result
Ctrl+U / Ctrl+D: scroll the preview up / down
Ctrl+X / Ctrl+V: open the result in a split / vertical split
Tab: mark a result; Alt+Q sends the marked ones to quickfix
Ctrl+Q: send every result to the quickfix list
Ctrl+R Ctrl+W: put the word under the cursor into the prompt
Ctrl+/ or ?: list the mappings (insert / normal mode)
Esc: normal mode in the prompt; Esc again closes
Enter: open the selected result
:Telescope Tab: list every picker
:Telescope git_files: search only the files git tracks
