%: jump to the matching bracket, brace or parenthesis
[[ / ]]: previous / next class or function (Python)
[m / ]m: previous / next method start (Java-like languages)
{ / }: previous / next paragraph
* / #: search for the word under the cursor, forward / backward
f{char}: jump to the next {char} on the line
t{char}: jump to just before the next {char} on the line
;: repeat the last f, t, F or T
viw: select the word
vip: select the paragraph
vi" / va": select inside / around the quotes
vi{ / va{: select inside / around a {} block
vit / vat: select inside / around an HTML or XML tag
V%: select the lines up to the matching bracket
zf%: fold up to the matching bracket
d% / c%: delete / change up to the matching bracket
diB / daB: delete inside / around a {} block
di) / da): delete inside / around a () block
